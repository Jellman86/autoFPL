# Model Card: Name/version

## Summary and status

Owner, status (research/shadow/serving/retired), code SHA, artefact hash and creation date.

## Intended decision and users

State exact intended use, horizon and users. List prohibited and out-of-scope uses.

## Training and data

Link immutable dataset cards/snapshots, feature availability boundary, train/validation periods, transformations, seeds, software lock and compute class.

## Method

Model family, objective, uncertainty method, calibration and relation to optimiser.

## Evaluation

Report baselines, walk-forward windows, proper scoring rules, calibration, intervals, decision metrics and material slices. Include all registered final tests.

## Limitations and failure modes

Cover missingness, injuries/rotation, rule changes, promoted teams, fixture changes, distribution shift and known weak slices.

## Monitoring and rollback

Define drift/calibration/performance thresholds, owner, review cadence, shadow comparison and tested rollback target.

## Ethical, legal and security considerations

Document data rights, privacy, manipulation/poisoning risks and whether any content was LLM-extracted.

## Approval

Links to registered experiment, independent review and promotion decision.
