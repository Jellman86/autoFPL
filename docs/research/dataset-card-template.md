# Dataset Card: Name/version

## Identity

Owner, immutable snapshot ID/content hash, schema version, creation time and retention class.

## Motivation and permitted use

Prediction purpose, source and collection method, intended private-research use, known access/retention constraints and public-redistribution boundary.

## Composition and coverage

Entities, fields, units, seasons, geography, sampling, missingness and known exclusions.

## Collection and revisions

Provider/source, collection method, cadence, `observed_at`, `available_at`, publication latency and correction/version policy.

## Processing and lineage

Raw snapshot IDs, transformation code SHA, quality checks, joins/entity resolution and feature leakage controls.

## Quality and bias

Schema/range/uniqueness results, source conflicts, representativeness, known biases and weak slices.

## Privacy and security

Personal/sensitive fields, minimisation, access, retention, deletion and incident owner.

## Maintenance

Owner, review cadence, deprecation/replacement and reproducibility command.
