# Bundled webfonts

Both families are self-hosted so the application has no external font
dependency and no viewer IP reaches a third-party CDN. Both are variable
fonts distributed under the SIL Open Font License 1.1; `OFL.txt` carries the
licence text.

| Family | Files | Copyright |
| --- | --- | --- |
| Bricolage Grotesque | `bricolage-grotesque-latin*.woff2` | Copyright 2022 The Bricolage Project Authors (https://github.com/ateliertriay/bricolage) |
| Work Sans | `work-sans-latin*.woff2` | Copyright 2019 The Work Sans Project Authors (https://github.com/weiweihuanghuang/Work-Sans) |

Each family ships two subsets, `latin` and `latin-ext`. The extended subset
is required: player names carry diacritics (Szoboszlai, Mbeumo, Guimarães).
